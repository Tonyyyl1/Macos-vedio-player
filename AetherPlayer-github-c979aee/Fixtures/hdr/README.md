# HDR fixtures

`mkv-hevc-main10-hdr10.mkv` is a two-second, 320×180 HEVC Main 10 clip encoded
from FFmpeg's deterministic test source with BT.2020 primaries, PQ (ST 2084)
transfer, and BT.2020 non-constant luminance matrix signalling. It contains no
third-party media. The fixture validates source HDR10 detection and the
playback route; it is not a display-calibration or screenshot-colour reference.

Synthetic SDR colour bars must not be relabelled as HDR fixtures.
